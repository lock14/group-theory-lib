# Security Policy

## Supported Versions

| Version | Supported          | JDK Target |
| :------ | :----------------- | :--------- |
| `2.x`   | :white_check_mark: | Java 25+   |
| `< 2.0` | :x:                | Java 8     |

---

## Reporting a Vulnerability

If you discover a security vulnerability within `group-theory-lib`, please report it privately:

1. **GitHub Security Advisory:** Open a private advisory under the [Security tab](https://github.com/lock14/group-theory-lib/security/advisories/new).
2. **Email:** Contact the maintainers directly.

Please do not open public issues for security-sensitive vulnerabilities. We appreciate your efforts to coordinate responsible disclosure.
